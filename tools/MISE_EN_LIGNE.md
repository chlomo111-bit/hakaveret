# הכוורת שלנו : mise en ligne

## 1. La base de données (Supabase, gratuit)
1. Crée un projet sur supabase.com (nom : hakaveret).
2. Ouvre **SQL Editor**, colle le contenu de `supabase.sql`, remplace `MOT_DE_PASSE_A_CHANGER` par ton mot de passe admin, puis **Run**.
3. Dans **Project Settings > API**, copie la **Project URL** et la clé **anon public**, et envoie-les-moi : je les mets dans le jeu.

## 2. Le site (GitHub Pages, gratuit)
1. Crée un dépôt GitHub public nommé `hakaveret`.
2. Mets dedans les fichiers du dossier `site` (`index.html` et `icon.png`).
3. **Settings > Pages > Branch : main > Save**. Le lien devient `https://TON-PSEUDO.github.io/hakaveret`.
4. Mets ce lien dans la bio Instagram.

## 3. Utilisation au quotidien
- **Ajouter une liste de noms** : ouvre le lien du jeu avec `#admin` à la fin, entre ton mot de passe, colle un nom par ligne.
  Mots possibles après le nom : מלכה, משקפיים, משקפי שמש, כובע, מגבעת, כובע גרב, פרח, פפיון, צעיף, ורוד, כחול, ירוק, סגול, אדום, כתום.
  Exemple : `@dana_k מלכה משקפי שמש`
- **Mode reel** : lien + `#reel`. Intro, puis les nouvelles abeilles du jour une par une, sans interface. À enregistrer en vidéo d'écran.
- **Billet caché** : un billet de 50 ₪ change de place chaque jour. Celui qui le trouve voit un code du jour (ex. `KV-Y8UY`) et l'heure. Le premier qui t'envoie la capture gagne.
  Change `secret: "change-me-kaveret"` dans le fichier pour que personne ne puisse deviner l'emplacement.
